# Pixel Agent Lab (Demo)

이미지 속 요구사항의 **1번(샘플 맵 + 캐릭터 구현)**을 빠르게 검증할 수 있도록 만든 데모입니다.

## 기술 스택

- **Vite + TypeScript**: 빠른 개발/빌드, 타입 안정성
- **Phaser 3**: 2D 맵/캐릭터/카메라/입력 처리에 최적

## 실행

```bash
npm install
npm run dev
```

빌드 확인:

```bash
npm run build
```

## 데모 기능

- 타일 기반 맵 에디터 (floor / wall / desk / chair)
- 플레이어 캐릭터 이동
    - WASD/방향키
    - 클릭-투-무브(A\* 경로탐색)
- 다중 NPC 에이전트 시뮬레이션
    - 에이전트 추가/제거
    - 랜덤 목적지 기반 이동
    - 속도 조절
- 시각화 옵션
    - 그리드 표시
    - 경로 오버레이
    - 충돌 타일 강조
- 카메라 제어
    - 마우스 휠 줌
    - (에디트 모드 OFF일 때) 우클릭 드래그 팬
- 맵 저장/불러오기(LocalStorage)
- 실시간 통계 + 이벤트 로그 패널
